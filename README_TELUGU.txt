VR Infinity AI — ఫోన్‌తో ఉపయోగించగల PWA వెర్షన్

ఈ ZIP APK కాదు. ఇది Progressive Web App (PWA) కోసం ఫైళ్లు. ఉచిత హోస్టింగ్‌లో HTTPS ద్వారా పెట్టిన తర్వాత Chromeలో తెరిచి "Add to Home screen" ఎంచుకుంటే ఫోన్ హోమ్ స్క్రీన్‌లో యాప్‌లా కనిపిస్తుంది.

ఫోన్‌తోనే ప్రచురించే సులభమైన మార్గం:
1. GitHubలో మీ స్వంత repository సృష్టించండి (ఉదా. vr-infinity-ai).
2. ఈ ZIPను Extract చేసి అందులోని నాలుగు ఫైళ్లు (index.html, manifest.webmanifest, sw.js, icon.svg) repository rootలో upload చేయండి.
3. Repository Settings > Pages లో Deploy from branch ఎంచుకుని main / root ను Save చేయండి.
4. GitHub Pages ఇచ్చే HTTPS వెబ్‌సైట్ లింక్‌ను Chromeలో తెరవండి.
5. Chrome menu (⋮) > Add to Home screen లేదా Install app ఎంచుకోండి.

గమనిక:
- GitHub Pages అందుబాటు/మెనూలు మారవచ్చు.
- ప్రస్తుత యాప్ ప్రాంప్ట్ టెంప్లేట్లు మాత్రమే చేస్తుంది. నిజమైన AI చిత్రం/వీడియో జనరేషన్‌కు API కనెక్షన్ అవసరం; అది ఈ ZIPలో లేదు.
- ఎవరికీ మీ పాస్‌వర్డ్ లేదా access token ఇవ్వకండి. మూడో పక్షం బిల్డ్ సైట్‌లో రహస్య credentials పెట్టకండి.
